# CourseLens 前端重设计方向复核

> **已被取代（2026-09-10）：** 本复核确立的“学习 / 搜索 / 课表 / 设置”四目的地信息架构已被 [docs/ui-academic-editorial-ia-guidance.md](../ui-academic-editorial-ia-guidance.md)（单一“学习”主场景）取代；本文件仅作历史记录，不再作为实现依据。

状态：设计决策，供后续实现模型执行；不是发布授权  
日期：2026-09-05  
基线：本地 `main` 当前含 `b811c3b`、`f597b36` 两个尚未推送的 v3 提交；`docs/handoff.md` 的既有用户修改必须保留

## 结论

采用 **Fluent 2 inspired CourseLens Study Workspace**：以 Fluent 2 的布局、导航、语义 token、平台习惯和无障碍原则为唯一设计参照，保留 CourseLens 自有绿色与原生 HTML/CSS/ES modules 实现。

这不是引入 Fluent React，也不是再写一套设计系统。现有 v3 已完成模块重组，下一步应在其上做最小结构校正。不要再次改模块名、重建 API 胶水或迁移技术栈。

当前 v3 的“两页三浮层 + Minimal Swiss”不作为最终信息架构，原因不是风格本身不好，而是它把长流程错误地藏进了浮层：

- 设置包含登录、隐私、远程连接、诊断和更新，是长流程，不应使用模态对话框。
- 全文搜索与 AI 回答可能形成长阅读面，不应在可层叠的搜索模态中完成。
- 任务是短时监控和少量动作，适合右抽屉。
- 当前 1000px 合成渲染中，播放器单独占一整行，字幕和笔记落到首屏以下；这没有兑现“边看边学”。
- 当前课程选择页在 28 门课程与 3 个讲次之间留下大面积空白；教师信息又被推到最右边，视觉关系松散。
- Windows-only 产品显示 `⌘K` 不合适，应显示 `Ctrl K`，同时兼容 `metaKey` 不必成为界面文案。

## 最终信息架构

顶栏保留四个稳定目的地：**学习、搜索、课表、设置**。任务是全局右抽屉，不是目的地；账户只负责显示会话状态及登录/退出入口；主题切换移入设置。

```text
┌ CourseLens ─ [学习] [搜索] [课表] [设置] ───── [Ctrl K] [任务 2] [账户] ┐
└───────────────────────────────────────────────────────────────────────┘

学习
  ├─ 课程与讲次选择
  └─ 学习桌
      ├─ 左：播放器、播放恢复、生成动作、直播状态
      └─ 右：字幕 / 笔记 / 资料 / 复习

搜索
  ├─ 全文结果与过滤
  └─ 基于结果生成回答

课表
  └─ 周视图 / 移动端日程视图

设置
  ├─ 账户与隐私
  ├─ AI 与处理
  ├─ 网络与远程连接
  └─ 更新与帮助

全局浮层
  ├─ Ctrl K 快速搜索：只负责跳转，选择“查看全部”进入搜索页
  └─ 任务抽屉：监控、暂停、继续、重试、取消
```

不新增首页、仪表盘、最近访问、推荐课程或伪造的学习进度。后端目前没有稳定的“最近访问”目录字段；只有在补齐受保护的进度读取合同后，才可增加“继续学习”。

## 核心屏幕

### 1. 课程与讲次选择

使用居中的两栏主从列表，最大宽度约 1040px。课程栏约 400px，讲次栏占剩余宽度；讲次元信息放在课程标题下方，不推到视口最右端。没有选择课程时，讲次栏显示一句说明，不显示空播放器。

```text
学习                                              [筛选课程] [刷新]
目录已验证 · 28 门
┌────────────────────────┬──────────────────────────────────────────┐
│ 课程                    │ 计算机网络 8                            │
│ 计算机网络 8            │ 林老师 · 2026-2027-1 · 计算机科学技术学院│
│ 林老师 · 3 讲           │                                          │
│                        │ 第 3 讲        2026-07-12 · 可播放       │
│ 线性代数 9              │ 第 2 讲        2026-08-11 · 可播放       │
│ 周老师 · 3 讲           │ 第 1 讲        2026-09-10 · 可播放       │
└────────────────────────┴──────────────────────────────────────────┘
```

列表行使用分隔线、留白和选中底色建立层级，不为每行制作卡片。当前项用 `aria-current="true"`，避免 `aria-pressed` 在辅助技术中被读成 checkbox。

### 2. 学习桌

在视口宽度 ≥960px 时必须同时看到播放器和一个学习内容面板。布局为 `minmax(520px, 1.7fr) minmax(320px, 1fr)`；目录通过“课程与讲次”按钮返回，不永久占第三栏。

```text
计算机网络 8 / 第 3 讲                         [课程与讲次]
┌───────────────────────────────────┬───────────────────────────────┐
│                                   │ [字幕] [笔记] [资料] [复习]  │
│          16:9 播放器              │ 00:12  当前字幕……            │
│                                   │ 00:18  下一行字幕……          │
│                                   │                               │
├───────────────────────────────────┤                               │
│ [生成字幕] [生成笔记]   任务状态  │                  [添加书签]  │
│ 直播状态 / 闭集恢复动作            │                               │
└───────────────────────────────────┴───────────────────────────────┘
```

右侧只保留四个一级标签：

- 字幕：跟随高亮、时间戳跳转、书签。
- 笔记：总结、章节、时间戳摘要。
- 资料：导入文档与文档列表。
- 复习：测验为默认子区；课程关系和学习回顾作为区内二级入口。

这些标签必须使用 `tablist`、`tab`、`tabpanel` 语义和完整键盘行为；不要继续用 `role="group" + aria-pressed` 模拟标签。

字幕模式不再常驻三个并列按钮。默认展示“生成字幕”；旁边用原生 `select` 或简单菜单选择快速/精准/标准，并给每种模式一句真实说明。生成笔记在缺少有时间戳字幕时明确显示“先生成字幕”，不做隐式串联任务。

播放器未加载时使用安静占位面，不显示大片黑色空视频；媒体加载后才显示真实 video。播放错误只呈现既有闭集原因与既有恢复动作。

### 3. 搜索

`Ctrl K` 快速搜索只显示最多 8 个跳转结果，Esc 关闭，Enter 打开。长结果、索引状态、过滤和 AI 回答都在稳定的“搜索”页面中完成。这样避免全屏模态、模态内再展开、Esc 多级回退和焦点栈。

不新增搜索 API，不在前端伪造索引能力：课程快速跳转复用已加载目录；全文搜索继续使用已有 API。

### 4. 任务

任务继续使用右侧抽屉。抽屉只承载当前与历史任务、真实进度、证据和后端允许的动作；远程连接配置留在设置页。

按钮必须逐项消费 `task.actions`。不得根据前端 `state` 自行推导暂停、恢复、重试或取消。保留 `display_state`、`control_state`、`stale` 和 operation id 的诚实语义。

抽屉打开时订阅 SSE，关闭时清理；后台已有活动任务时，顶栏任务按钮显示数量。失败但无活动任务时显示文字可理解的失败标记，不能只靠红点传达。

### 5. 设置

设置是普通顶级页面，不是 `aria-modal` 对话框，不圈闭焦点。内容最大宽度 1040px，左侧窄分组导航，右侧单列设置项：账户与隐私、AI 与处理、网络与远程连接、更新与帮助。

手动代理地址只在网络模式为“手动代理”时出现。诊断原始闭集信息默认折叠。危险动作保持二次确认与失败恢复；凭据字段、DPAPI 语义、隐私披露和诊断脱敏规则完全不变。

## 视觉系统

选择 Fluent 2 是为了适配 Windows 桌面工具，而不是复制 Microsoft 外观。使用平台字体、4px 间距基线、少量圆角、语义 token 和克制层级。CourseLens 绿色继续作为唯一品牌强调色；蓝、绿、橙、红不得同时作为装饰色。

建议核心 token：

| Token | 亮色 | 暗色 |
| --- | --- | --- |
| 页面底 | `#F5F6F8` | `#17191C` |
| 内容面 | `#FFFFFF` | `#202327` |
| 次级面 | `#EFF1F4` | `#282C31` |
| 主文字 | `#202124` | `#F2F3F5` |
| 次文字 | `#5F6368` | `#B4BAC4` |
| 分隔线 | `#DDE1E6` | `#3A4048` |
| 可交互边界 | `#747B85` | `#8A929F` |
| 主色 | `#0F6C52` | `#75C9A5` |
| 主色柔和底 | `#E7F2EC` | `#223C31` |
| 主按钮文字 | `#FFFFFF` | `#112B21` |

已按 WCAG 相对亮度公式复核：主文字/页面底为 14.89:1（亮）和 15.86:1（暗），次文字/页面底为 5.59:1 和 9.03:1，主按钮文字/主色为 6.39:1 和 7.66:1，可交互边界/页面底为 3.95:1 和 5.61:1。

页面正文 14px/20px，阅读内容 16px/26px，页面标题 24px/32px；不使用小于 12px 的文字。阴影只用于任务抽屉、快速搜索和真正的模态确认；普通分区用留白和 1px 分隔线。禁用渐变、玻璃拟态、巨大品牌字、装饰性插画、整页卡片网格和在线字体。

桌面控件最小高度 32px，主要操作 36–40px；`pointer: coarse` 下触达区域至少 44px。所有图标复用现有 vendored Tabler SVG。

## 响应式规则

| 宽度 | 行为 |
| --- | --- |
| ≥1280 | 顶栏四目的地；学习桌左右双栏，右栏 360–440px |
| 960–1279 | 顶栏仍完整；学习桌左右双栏，右栏至少 320px |
| 720–959 | 学习桌上下堆叠；内容标签保持；课程选择两栏 |
| <720 | 底部四项导航；课程与讲次改单栏逐级进入；任务全宽抽屉 |

验收至少覆盖 375、720、900、1000、1280、1440px，亮暗双主题及 200% 浏览器缩放。1000px 是本次必须单独验收的关键视口：播放器与当前学习内容必须同屏左右排列，顶栏所有操作不能被裁切。

## 不可破坏的实现合同

- 继续使用唯一 `store.activeLecture` 驱动播放器与学习内容；不得创建第二套“当前讲次”状态。
- 保留播放器 `timeupdate/seeked` 与字幕时间戳跳转的双向事件。
- 保留字幕/书签/直播的 epoch、AbortController 和清理逻辑，防止旧讲次结果覆盖新讲次。
- 保留 API v3、operation id、闭集错误和脱敏诊断；不修改 `src/**`、`worker/**`、`runtime/**`。
- 不新增依赖、框架、在线字体、图标包或动画库。
- 不承诺后端没有的最近访问、推荐、跨课程进度或离线能力。
- 不通过删除或放宽安全测试来适配新 DOM。
- `docs/handoff.md` 的既有未提交修改属于用户，严禁覆盖。

4. 修正课程选择页宽度、元信息邻近关系、标签语义、空播放器和手动代理渐进披露。

## 设计依据

- Fluent 2 布局强调用邻近和间距建立关系，并要求主从布局在窄屏重新编排，而不是机械挤压：[Layout](https://fluent2.microsoft.design/layout)
- Fluent 2 导航建议把高层目的地保持为易访问、结构一致的入口：[Nav usage](https://fluent2.microsoft.design/components/web/react/core/nav/usage)
- Fluent 2 drawer 适合补充信息与短操作，复杂长流程应使用专注页面：[Drawer usage](https://fluent2.microsoft.design/components/web/react/core/drawer/usage)
- 标签应实现 `tablist/tab/tabpanel`、方向键和焦点行为：[WAI-ARIA Tabs Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)
- 同时展示来源与笔记、并保留时间位置链接，是成熟学习工具中已验证的阅读模式：[Zotero PDF Reader](https://www.zotero.org/support/pdf_reader)
