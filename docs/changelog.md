## [0.1.1] — 构建于 2026-10-02（桥接发布，已定版收编）

> 本版是发布仓改名期（WINIT-1）的桥接发布。2026-10-04 起公开渠道统一定版
> **0.1.0**：本版内容连同 0.1.1 之后的全部学生可感知增量，都收编进了重新发布
> 的 `client-v0.1.0` 定稿构建（见下方 [0.1.0] 一节）。已装 0.1.1 的同学不会
> 收到更新推送（同号换装不触发、更不会降级），现有版本继续可用；新下载的同
> 学拿到的就是定稿构建。

### 新

- 考核联动：平台考核相关内容进入学习链路（总结/笔记/复习均可见）。
- 学习事件与术语候选：学习过程中的关键事件入记忆，术语候选辅助复习沉淀。
- 发布仓改名就绪：官方发布仓指向 `Fudan-CourseLens-Worker-Release`（过渡期旧链接自动跳转，无需手动处理）。

### 改

- WebVPN 课程流改两段式取流，长视频更稳。
- 媒体预取带完整性门，损坏片段不再静默入包。
- 更新通道信任面升级为生产签名（对使用者无感，校验更严）。

## [0.1.0] — 定稿构建 2026-10-08（首个公开发布版本·同版号换装重发布；发布日期以[官方发布页](https://github.com/gualtier-xu/Fudan-CourseLens/releases)为准）

> 2026-10-01 首次公开发布，此后持续打磨；本节为**定稿构建**的完整清单
> （首发内容 + [0.1.1] 内容 + 其后全部学生可感知增量，同版号整体换装）。
> 逐条事实与措辞见 [0.1.0 发布定稿](release-notes-0100-draft.md)。

### 新

- 首次安装：`CourseLens-0.1.0-setup.exe`（装前可对照《校验单》核对 SHA-256；
  仅用于首次安装，之后的升级在应用内完成——有新版本会告诉你，装不装由你确认）。
- 选课入口秒进：打开应用直接看到上次的课程列表，不再对着「正在登录」空等。
- 启动直达真界面：打开应用后几秒内直接进入主页，不再出现「正在启动」过渡页；
  万一启动失败会弹出说人话的错误页，不会让你对着黑窗猜。
- 校外也能看网课：不用改任何设置——校内直连、校外自动走学校官方通道（原
  「WebVPN 中转」开关已退休）。
- 复习页自动长出知识脉络；同一门课反复出现的术语自动沉淀进课程记忆（可撤销，
  撤销后不再自动使用），之后生成的材料更贴合老师的讲法。
- AI 总结导入后自动做一次质量抽检：讲次卡三态结论（通过 / N 处存疑 / 未抽检），
  存疑处用人话列出，仅供参考。
- 考核联动：平台考核相关内容进入学习链路（总结/笔记/复习均可见），学习事件与
  术语候选一并沉淀。
- 「你的数据在哪里」数据地图：设置页一屏看清各类数据存在哪、谁能看到什么。
- 数据搬家与备份：学习数据一键打包带走、原路搬回，换电脑重装不丢资料。
- 界面字号三档（小/标准/大）随时切换；三种主题（浅色/深色/跟随系统）不变。
- 云端任务跟着课表智能排程：工作日课余自动补扫，不再固定时间空转。

### 改

- 字幕更快更稳：平台课粗字幕先行、精细校对跟上；中途登录过期自动续接；转写
  管线升级为流式处理，长讲次出稿更连贯。
- 大讲次字幕打开提速：十几兆的长字幕从近二十秒缩短到一秒级，滚动浏览顺滑
  （界面按需渲染看得见的部分，内存占用大幅下降）。
- 窄窗口适配：小窗口（如分屏、竖排布局）下顶栏与播放控件不再溢出。
- 校外课程流两段式取流，长视频更稳；媒体预取带完整性门，弱网下并行分段，
  损坏的片段不再静默入包；慢加载如实提示进度。
- AI 总结、提问等文字任务的云端处理平均快了约三分钟（不再排队等待媒体环境准备）。
- 主题默认「自动」（19:00-7:00 深色）；卸载默认保留你的学习数据，选「否」才会删除。
- GitHub 连接状态每分钟自动复验，连不上时给出代理设置指引；界面静止时后台
  循环降载，空转更省电。

### 修

- 再次打开应用直接回到正在看的课堂（不再退回浏览器）；冷启动等待有开机画面陪伴。
- 修复了学校服务闪断时被弹回首页、桌面点不动、退出后耳机里仍有声音的问题——
  原地保留正在看的课，服务恢复后一切照旧。
- 修复了新安装时打开「考核雷达」报错的问题，开箱即用。
- 修复了部分云端字幕没有标点的问题：标点服务已在云端恢复上线，新生成的字幕
  长句正常断句（恢复前生成的旧字幕保持原样）。
- 修复了任务列表偶尔卡住、断连横幅常驻的问题；自动整理开关恢复生效；重置页
  新增课程排序/学期筛选；多处崩溃与卡顿修复（详见技术仓库提交记录）。
- 播放更顺手：修复播放键偶尔失灵、回车误触目录、切换讲次时进度被误清的问题。
- 历史残留死任务自动归档清理，「重装也删不掉的残留任务」根治。
- 修复撤销课程记忆后云端复核卡住、反复空转的问题；校外看课会话偶发失败根治。
