# 云端无人值守自动化（自动学习材料）

状态：本地合成验证完成；真实云端链路（S09-L）尚未验收，未开启。

## 合同（cloud-automation.v2）

自动学习材料是显式 opt-in 的云托管流程。开启前客户端必须完成五步事务序列：

1. **配置（停用态）**：选择本机已保存账号、课程（默认全不选）与输出；
2. **披露确认**：勾选绑定版本的托管披露（目标仓库、Environment Secrets、
   无法读回、撤销效果），勾选框默认未选；
3. **加密上传**：后端仅在本动作内通过既有 `CredentialStore` 读取所选账号
   凭据，sealed-box 加密写入用户自己的 Worker 仓库 `courselens-worker`
   环境；GitHub 只回读 Secret 名称清单，值永不出现在本机数据库、日志、
   事件流或 API 结果；
4. **云端验证**：一次专用验证工作流登录课程平台并核对所选输出所需的
   AI Key，成功后写入带签名回执的加密状态 Artifact；
5. **启用**：本机核对签名回执与配置哈希一致后，才写入
   `COURSELENS_CLOUD_ENABLED=true` 并启用计划工作流；任一阶段失败都
   回滚并保持停用。

配置哈希绑定：协议版本、披露版本、Worker 仓库/树/manifest/trust epoch、
所选账号、凭据代数、预算与课程规则。任一变化使验证失效并停用计划任务。

## 固定计划

每天两个窗口：**13:00 与 22:00（Asia/Shanghai）**，即 GitHub Actions
UTC cron `0 5 * * *` 与 `0 14 * * *`。本阶段不提供用户可配置时间，
也不保留旧版 24 条半小时 fanout 与 `COURSELENS_CLOUD_CRON` 选择器。
手动 run-now 仅在验证通过后可用。

## 运行与幂等

Worker 只发现授权课程；讲座仅在播放可用后参与处理；幂等键 =
账户/配置哈希/课程/讲座/请求输出/管线指纹的规范哈希。已完成或处于
pending（24 小时 TTL）的条目不重复运行；失败、延后（预算耗尽）保持可
重试。已知凭据被拒、票据/会话被拒或身份不符立即打开账号熔断；AI 与
平台瞬时故障使用各自的有界熔断；预算耗尽延后剩余工作并写入诚实的加
密状态结果。

## 数据与保留

结果与增量状态始终加密（状态另含签名回执）。结果 Artifact 保留
90 天（项目支持的有界上限），客户端如实显示上限与每条截止时间；本机
对账精确一次导入（验签、输入摘要、配置绑定）后即安全清理云端副本；
到期未导入按不可恢复如实上报。

## 操作区分

- **暂停自动处理**：停计划、保留托管数据；
- **立即检查**：验证通过后派发一次运行；
- **更新账号**：重新上传所选账号并重新验证，成功后才恢复计划；
- **删除云端凭据与状态**：两步确认；先停用再有界等待活动运行终止，
  按精确名称删除 Secrets/Variables/Artifacts 并核实清空；歧义时不盲
  重试，进入可恢复的 `cleanup_pending`。

## 在线验收门（S09-L）

真实凭据上传 → 验证 → 两条计划路径（或等效手动触发）→ 加密结果导入 →
撤销 → 零残留，必须在精确的受管仓库上单独授权验收。此前产品不声称
真实云端支持；本文件描述的合同已经过本地合成验证。

按需 Worker 任务、Mailbox、签名结果和加密 Artifact 的既有职责不受影响。
