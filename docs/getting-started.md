# CourseLens 快速上手（写给第一次使用的学生）

本页是「每天怎么用」的主线速览；首次安装、GitHub 授权与故障恢复的完整说明见[《学生新手教程》](student-onboarding.md)。客户端里的文案以实际页面为准，本页与页面文案同源（2026-10-06 与 0.1.0 版逐一核对）。

## 先用一句话理解它

CourseLens 运行在你自己的电脑上：课程目录、课表、字幕和学习记录都存在本机；字幕、摘要这类重计算按你的设置用加密云端处理，结果加密回传。在你明确点击登录、刷新或生成之前，它不会自动访问学校平台或发起远程任务；唯一的例外是「自动学习材料」——你主动开启后，它也只在你确认过的固定窗口（每天 13:00 / 22:00）自动运行，随时可以关掉。

## 第一次启动（约 5 分钟）

1. 从[官方发布页](https://github.com/gualtier-xu/Fudan-CourseLens/releases)下载安装包并校验后安装（校验与安装三步见 [README「三步开始」](../README.md#三步开始)），装好后从开始菜单打开 CourseLens；首次启动要准备本地服务，等几秒进入主界面属正常。
2. 首次安装会自动打开一次五步引导：**先了解工作方式 → 连接复旦课程平台 → 确认课程目录 → 准备生成能力 → 开始学习**。引导可以随时跳过，之后可在「账户菜单 → 新手引导」或「设置 → 更新与帮助」重新打开。
3. 按引导先用复旦统一身份认证登录连接课程平台、确认课程目录；「准备生成能力」一步会完成 GitHub 授权并创建你的两个专属云端仓库（用于加密云端处理）。学号、密码和 DeepSeek API Key 只输入客户端的受保护密码框，经 Windows 加密后存盘。
4. 回到「学习」页点「选择课程」，客户端会列出当前账号实际有权访问的课程。没看到课，先点「刷新」；还不行就看「诊断信息」。

详细的授权与安装步骤（含 App 安装范围收紧、仓库初始化）见[《学生新手教程》](student-onboarding.md)。

## 每天怎么用

- **打开就学**：主页按时段问候，常驻一张可点击换一句的诗词签；「今日与本周安排」卡片显示下一节课和教室，「直播」卡片在检测到直播课时出现，点「进入直播」即可。
- **选课**：顶栏「选择课程」或按 `Ctrl K` 搜索课程、讲次和文稿内容。
- **进入讲次**：点「选择课程」后在课程详情里点讲次行，播放器和字幕并排出现。
- **主题**：在「设置」里可把界面切成浅色、深色或自动；自动档每天 19:00 到次日 7:00 用深色，选择保存在这台电脑上。

## 看课与字幕

- 播放器控制条：播放/暂停、时间轴、音量、倍速（下拉或 `>` / `<` 九档）、字幕开关、画中画、影院、全屏；鼠标不动约 1.5 秒自动隐藏（暂停时也一样）；只要停在控制条上就不会隐藏，动一下鼠标或触控板即重新出现。
- 常用键位（播放器内按 `?` 看全部）：`空格` 播放暂停；`←`/`→` 快退快进 5 秒（按住临时 3 倍速）；`J`/`L` 10 秒跳转；`X` 标记「没听懂」；`↑`/`↓` 音量；`C` 字幕开关。
- **字幕样式**：点住「字幕」按钮约半秒（长按），可调字号、背景深浅和贴底位置；改动立即生效，只保存在这台电脑上。
- **没听懂**：控制条点「没听懂」（或按 `X`），当前时刻会插一面小旗，之后点击小旗跳回重听；时间轴下方旗标悬停可让 AI 解释、标记「懂了」，或点「删除」把这面旗彻底移除（删除后时间轴上不再显示）。
- **不想留下观看热点**：播放器下方点「抹掉本讲热点」，按提示再点一次确认，只清这一讲的回看热点，字幕、课件和学习记录都不受影响。

## 生成字幕与 AI 学习资料

- 讲次下方「生成字幕」「AI 处理」负责把这一讲变成字幕、总结和章节；已排入自动处理时按钮区会说明「本讲的字幕与 AI 处理由云自动化完成，不用手动发起」。
- 进度和结果统一在顶栏「任务」抽屉里看：进行中的任务显示已等待时长与当前阶段，失败的任务会用一句人话说明原因（例如「云端处理没有完成。稍等几分钟重试通常可以恢复」），可展开「技术详情」看闭集错误码。
- 生成好的总结、课件 PDF 和资料都在讲次右侧「总结 / 资料」面板；有讲次上下文时「生成课件 PDF」可用。
- 任务记录可清理：失败的任务卡可单条删除或一键清空（自动材料记录删除后重启也不会自己回来），只删记录，已生成的字幕、总结和课件 PDF 都不受影响。
- 想知道 AI 花了多少：AI 处理完成的任务卡会显示本次 token 消耗；「设置」的 AI 区还有本月云端消耗汇总（按本机记录累计，仅供参考）。

## 复习

课程卡里点「总体复习」进入课程级复习，三个视图：

- **知识脉络**：这门课被整理出的主题与它们在字幕、课件里的出处；
- **按课次**：每讲的知识点清单与就绪状态（「待更新」表示资料有更新，可点「更新课程知识」刷新）；
- **练习与真题**：作业/真题的题目、官方答案（如有）与「生成 AI 解答」，下面是本课程练习（来自课程字幕的回忆题，做错的排在最前面）。

## 数据与隐私

- 数据都在本机（安装版位于 `%LOCALAPPDATA%\CourseLens\data`）；「账户菜单 → 数据管理」可以导出、清理派生数据或删除记录，每个按钮删什么、能不能恢复都有说明。
- 隐私边界（谁能看到什么、客户端和哪些服务器通信）见 README 的[「安全与隐私架构」](../README.md#安全与隐私架构)一节，页面内也可看「设置 → 查看[《隐私与数据说明》](privacy-notice.md)」。

## 出问题了

先看[《学生新手教程》](student-onboarding.md)的恢复章节；客户端内的错误提示都带人话文案，照着提示做通常一步就能恢复。客户端有新版本时，「设置 → 更新与帮助」的更新卡会显示新版本号和本版说明；客户端会自动检查新版本，但要不要升级、什么时候升级由你确认（不会静默安装）。
