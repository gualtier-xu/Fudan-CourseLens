# 媒体防泄露护栏：防什么、不防什么（诚实边界）

这份说明讲清楚客户端在课件与视频上做的防泄露处理，以及它**不能**做到什么。
我们宁可把边界说清楚，也不给你一个"绝对安全"的错觉。

## 已拦下的（客户端护栏）

- **播放器与图片上的右键菜单**：右键"另存为/复制图片"这类入口不再弹出
  （视频画面、PPT 页面图、界面图标都在内）。
- **图片、视频拖出窗口**：按住拖到桌面或聊天窗口的路子被拦掉。
- **Ctrl+S / Ctrl+U**：浏览器的"保存网页/查看源代码"快捷键被拦截。
- **播放器下载与投屏入口**：视频控件自带 `nodownload` 与禁用远程播放。
- **不误伤学习动作**：输入框、搜索框、可编辑位置的右键（复制/粘贴）完全
  保留；输入框里的 Ctrl+S/U 也仍是浏览器默认（"保存/查看源代码"只拦输入框
  外的误触）；课程列表的拖拽换位也照常可用；文稿文字照常可以选中复制。

## 防不了的（诚实边界）

- **开发者工具的网络面板**：视频和页面图终究要传到你电脑上才能播放，
  会用抓包工具的人可以看到这些流量。
- **录屏、拍照、截屏**：内容一旦显示在屏幕上，软件层面无法阻止外部设备
  记录它。

## 为什么仍然值得做

护栏挡住的是"顺手另存""误拖出去"这类**无意识的**扩散路径——大多数泄露
不是蓄意攻击，而是随手一拖。抬高随手扩散的门槛，就是护栏的全部目的；
它不承诺对抗有技术手段的蓄意行为。

你的课件、字幕、笔记始终保存在**你自己的电脑**上（本地优先，见 README
「安全与隐私架构」一章），不经由任何第三方服务器中转。
