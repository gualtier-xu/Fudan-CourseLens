## CourseLens：把课程视频变成你的复习材料，数据留在你自己的电脑上

**它是什么**：一个装在你电脑上的课程助手。选好课后，它能给录播生成字幕和笔记，把「没听懂」变成复习清单，考试前一键整理重点。直播课也有专属页面和实时字幕。

**你的数据在哪里**：
- 课程记录、字幕、笔记、账号凭据——**默认只存在你的电脑上**（凭据用 Windows 加密，只有你本人能读）。
- **外联只在固定清单内**：课程与身份只连学校官方服务，任务只连你的 GitHub 专属仓库，AI 校对只连 DeepSeek（你自己的 Key，可选）——清单之外没有任何联网目标。
- 生成字幕/笔记时，音视频片段会**加密后**送到你的专属云端任务，处理完即弃，我们不留存。
- **永远不会发生**：没有埋点遥测、不上传你的浏览行为、不卖任何数据。

**谁能看到什么**：只有你。云端任务用一次性加密通道，连我们自己也读不到内容明文；更新包全部经签名验证，验不过就不装。

**怎么开始**：到官方发布页（[github.com/gualtier-xu/Fudan-CourseLens/releases](https://github.com/gualtier-xu/Fudan-CourseLens/releases)）下载安装包 → 用复旦账号登录 → 选课，三步。遇到问题时，点设置里的「诊断信息」截图发我们，或到[官方仓 Issues](https://github.com/gualtier-xu/Fudan-CourseLens/issues) 提问。

**安装小贴士（第一次装看这里）**：
- 如果 Windows 弹「已保护你的电脑」：点「更多信息」→「仍要运行」。新软件还没有积累下载量时都会有这一步（我们现阶段没有购买代码签名证书，如实说明）；安装包有没有被动过手脚，请对照安装包旁《校验单》里的 SHA-256 核对（像核对快递单号一样，两串数字一致就放心装）。逐步图文版见《Windows 安全提示图文指引》（随发布页附上）。
- 如果装不上或卸不掉：先看 Windows 安全中心 → 应用和浏览器控制 → **Smart App Control** 是不是开着。它有时会拦下还没有签名记录的新软件（本安装器当前不签名）；被拦的具体文件可以在「事件查看器 → CodeIntegrity」日志里看到名字，把那一页截图反馈给我们最快。
- 只装一次就好：以后升级 CourseLens 会**在应用里**提醒你，装不装由你确认，不用重新跑安装包；卸载时你的学习数据默认原地保留。
- 升级装不上（setup.exe 提示已安装等）：请回到应用内更新，不要反复跑安装包——安装包只负责第一次。
