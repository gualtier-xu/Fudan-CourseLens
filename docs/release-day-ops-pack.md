## 3. 渠道观测指标（发布后 72 小时）

- Release 资产下载量（setup.exe / 校验单 / 安全指引页 / 更新包 zip）——每日一记。
- 更新链闭集错误码分布（客户端健康事件里 policy_blocked / download_http_error / manifest_signature_invalid 应为零；非零即通道异常）。
- 首个真实任务闭环完成数（派发→回传→导入→复习可见）。
- 卸载保留-重装路径的异常报障数（预期零，见 runbook §C）。
- 阈值动作：下载量 24h=0 或错误码非零 → 先查渠道 URL 三件（DISTRIBUTION_REPOSITORY/release 资产名/信任三件），不动产品码。

## 3b. 校验单 vs SHA256SUMS：两种文件，别混（D2 修订）

- **学生可读《校验单》**＝`output\installer\CourseLens-<版本>-校验单.txt`（`installer\build_installer.ps1`
  生成、随发布页上传）：人类可读格式（`SHA-256: …` + certutil 一行命令核对指引，与 README、
  安全指引页三处同口径）。**不要对它跑 `sha256sum -c`**——学生核对口径是 certutil 单行命令。
- **工具链 SHA256SUMS 文件**（灾备/复核用，实例=`backup/SHA256SUMS-20260925.txt`）：文件头固定两行
  注释（中文面向同学、英文面向工具链），**正文必须是严格 `sha256sum -c` 兼容两空格行
  （`hash␣␣filename`），注记一律写进 `#` 注释行**（N9-R 05:40 实测：带行内括号注记的行会让 `-c`
  报 malformed；重制后 bundle 行 OK、产物行与产物同目录即可过）。生成命令固定：

```bash
sha256sum CourseLens-0.1.0-setup.exe >> SHA256SUMS-YYYYMMDD.txt
```

## 4. 支持渠道话术（讲人话版，直接可贴）

- 装不上：「先确认电脑上没有装过 CourseLens——安装包只负责第一次安装。装过的话，打开 CourseLens 点设置里的检查更新就行。第一次装遇到 Windows 蓝色拦截提示，照着《Windows 安全提示图文指引》（`docs/release/windows-security-prompt.md`，随发布页附上）一步步点就行。」
- 更新失败：「别慌，更新链是『验签不过就不装』的设计——你不会装到坏包。重启一次 CourseLens 再试；还不行，把设置页『诊断信息』展开截图发我们。」
- 卸载会丢数据吗：「卸载时会问你『要保留你的学习数据吗』——选『是』（推荐默认），笔记进度都在；哪天重装回来一切如旧。选『否』才是真删，不可恢复。」
- 隐私三句：「字幕笔记在你自己电脑上生成；我们零遥测、不上传行为数据；要连云端处理时会先征得你同意。」

## 7. 回滚触发判据卡（发布前成文——业界铁律）

满足任一条立即触发回滚，不讨论不观望：
- R1：渠道 manifest 验签失败报障 ≥1 例（信任链疑点，最高优先）。
- R2：更新后客户端无法 ready 的报障 ≥2 例（独立机器）。
- R3：首个真实任务闭环 4 小时内零成功且渠道错误码非零。
- R4：任何一条学生数据完整性疑报（数据红线，无条件停）。

回滚动作序：①渠道 release 转 draft（下架 manifest）②客户端侧 fail-closed 保证旧版继续可用，无需用户动作 ③按 runbook §8 用信任三件 `previous` 锚与 §1 灾备 bundle 恢复 ④复盘记录。

## 8. 灾备 bundle 定期化方案

- 触发：每次 finalizer 本地提交后 + 每次发布上镜后。
- 命令：runbook §1 四证（bundle→verify→试克隆→校验单追加）。
- 保留：`backup/` 按日期留最近 3 份+全部「发布日」份；每份必配 SHA256 行。
- 实测成本：全史 5.9MB / 2 分钟（N9-R）——周级即可，无借口。
- 恢复顺序（N9-R 实证）：bundle 试克隆（HEAD 恒等）→ 恢复树 compileall 可运行 →
  **捆绑运行时/venv 不在 git 内**（设计如此）：补 `tools/python312`（用 `runtime-assets.json`
  的 python.sha256 锚核对）→ 重建正典 venv → 跑定向集。全环境级恢复另见
  archive cleanroom-restore-set。
