## 版本 0.1.0（定稿构建 2026-10-09；发布日期以官方发布页为准）

### 新：你现在可以……
- 一键把课程变成可复习的材料：录播自动转写字幕；错过直播可在讲次列表看**老师授权的回放**；课件 PDF 一键合成（中断了还能续跑）。

- 「你的数据在哪里」一屏看清：设置页新增**数据地图**，课程记录、字幕、笔记、账号密码各存在哪、谁能看到什么，一目了然。
- 数据搬家与备份：换电脑、重装系统不用怕，学习数据可以一键打包带走，也能原路搬回来。
- 复习页会自己长大：导入课件或生成字幕后，要点脉络自动整理；同一门课反复出现的术语自动沉淀进这门课的记忆，之后生成的材料更贴合老师的讲法。每条记忆都能看到来龙去脉（自动确认 · 信号 ×N），觉得不对点「撤销」就好，撤销后不会再被自动使用。
- AI 总结导入后会自动做一次质量抽检：讲次卡上给出三态结论（抽检通过 / 抽检完成 · N 处存疑 / 未抽检），存疑处用人话列出。提醒仅供参考，内容本身可以直接用。
- 平台考核相关内容进入学习链路：总结、笔记、复习都能看到，学习事件与术语候选也一并沉淀，期中周更安心。
- 挑自己喜欢的样子：浅色、深色、跟随系统三种主题随时切换；界面字号也能在设置里选「小 / 标准 / 大」三档。
- 云端任务更省心：任务进度随时可查、失败自动补扫，补扫跟着你的课表智能排程（工作日课余自动跑，不再固定时间空转）；关闭软件也没关系，结果回来会自动导入。
- 首次提供 macOS 测试版（Apple Silicon 机型，macOS 12 及以上）：走发布页的测试版通道下载，功能与 Windows 版同步内测中，欢迎帮忙踩坑。
- 连接 GitHub 一步到位：首次设置时的授权、初始化、加密测试全程自动推进，你只需要点两次按钮、在网页登录一次；验证码快过期会提前倒计时，过期了也会自动换新，不用从头再来。
- 进度条可以放心拖了：拖动时先预览位置，松手才真正跳转，校外慢流下也不会拖一下卡一路。
- 打开讲次会自动从上次的位置继续播；想从头看，点浮层里的「从头看」就好（它不会打断你，Esc 随时能关）。
- 数据页的「没听懂」有数了：标记总数直接上屏，点开明细能看到具体在哪；没有统计数据的栏目也会说明原因，不再留下看不懂的「—」。

### 修：……更稳了
- 再次打开 CourseLens 更顺了：双击图标直接回到你正在看的课堂，不再退回浏览器；冷启动的短暂等待也有开机画面陪伴，不再对着任务栏干等。
- 修复了学校服务闪断时被弹回首页、整个桌面点不动、退出后耳机里还有声音在放的问题：现在原地保留你正在看的课，服务恢复后一切照旧。
- 修复了新安装时打开「考核雷达」报错的问题，现在开箱即用。
- 修复了部分云端生成的字幕没有标点的问题：标点服务已在云端恢复上线，新生成的字幕长句正常断句（恢复前生成的旧字幕保持原样，不会自动补标点）。
- 长视频更稳：校外课程流改两段式取流；媒体预取加了完整性门，损坏的片段不再悄悄混进字幕包；弱网下预取改并行分段，字幕包更完整，慢加载时也会如实提示进度。
- 字幕转写管线升级为流式处理，长讲次出稿更连贯。
- 大讲次的字幕打开更快了：十几兆的长字幕从近二十秒缩短到一秒级，滚动浏览也顺滑不打顿（界面只渲染看得见的部分，更省内存）。
- 窄窗口也整齐了：小窗口（如分屏、竖排布局）下顶栏按钮和播放控件不再挤出屏幕外。
- 播放更顺手：修复了播放键偶尔失灵、回车误触目录、切换讲次时进度被误清的问题，继续播放回到原位。
- 任务列表清爽了：历史残留的死任务会自动归档清理，「重装也删不掉的残留任务」根治了。
- 修复了撤销课程记忆后云端复核卡住、反复空转的问题。
- 校外看课的会话偶发失败已根治；GitHub 连接状态每分钟自动复验，连不上时直接给你代理设置指引（校园网直连 GitHub 不通畅时的常见解法）。
- AI 总结、提问这类文字任务的云端处理平均快了约三分钟（不再排队等待媒体环境准备）；界面静止时后台循环降载，空转更省电。
- 拼音打字更安心：用输入法组词时，回车、方向键、Esc 都只属于输入法，不会再误关浮层、误清搜索框或误触其他操作。
- 新手引导中断了也能接上：主页会出现「继续新手引导」的提示，菜单里的引导入口也能直接回到上一步。
- 「进入直播」只需要点一次；收藏失败时的提示换成了好好说话，不再让你觉得是自己的错。
- 状态更诚实：某个校园服务暂时连不上时，会点名是哪一个，不再笼统地说「不正常」；「检查更新」按下立刻有回应，结果也给你一句明确的答复。
- 磁盘满了会好好说话：启动时若磁盘空间不足，会提示你清理空间，并如实告诉你数据没有受影响；数据文件比软件新时，会引导你升级 CourseLens，而不是让你拿旧备份去覆盖新数据。
- 同一台电脑开两个 CourseLens 时，第二个会明确提示程序已在运行、端口被谁占用，不再出现两个实例悄悄共用端口、请求随机走丢的情况。
- 一批日常顺手的走查修复：没关联课程的任务不再被贴错标签；缺授权的任务重试前会先检查，不再白白失败一次；搬家或清理被拒绝时能拿到完整的人话说明；深色模式按钮在读屏软件里也能读对状态。

### 安：……更安全了
- 你的课程记录、字幕、笔记、账号密码默认只存在你自己的电脑上（密码用 Windows 自带加密，只有你能读）；AI 全部在你的专属云端 Worker 上执行，你的电脑上没有任何 AI 模型。数据存在哪、谁能看到什么，设置页的「数据地图」一屏可查。
- 需要云端 AI 处理时，音视频片段先加密再上传，处理完即弃；没有任何埋点遥测，浏览行为不会被上传。
- 和哪些服务器打交道有一张固定闭集清单：学校课程与身份服务、你的 GitHub 专属仓库、可选的 DeepSeek，清单之外没有任何联网目标。本版把清单做了一轮逐主机对账（现为 10 个），云端任务的加密信封里带什么、谁能解封，也写进了公开说明。更新到本版即可，无需任何操作。
- 更新全程验签：更新清单必须通过签名校验，验不过就不会安装；有新版本时应用内告诉你，装不装、什么时候装由你确认（默认不静默），更新后启动不健康会自动回滚到上一版。
- 《隐私与数据说明》更新到了 v1.2，把「你的数据在哪里、谁能看到什么」写得更清楚；完整说明在 README 的《安全与隐私架构》一章，应用内设置页也能随时打开《隐私与数据说明》。
- Windows 的卸载条目补全了：「设置 → 应用」里的 CourseLens 卸载项现在有完整的名称、图标和卸载入口，新装的机器桌面快捷方式也不再悬空。
- 隐私页的证据更明白了：本地学习统计默认关闭时，如实写「未开启（不影响使用）」，想开启也有一键入口，不再出现没有解释的「需要完成操作」。
