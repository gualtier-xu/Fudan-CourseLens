```markdown
## 版本 0.1.2（YYYY-MM-DD，发布日实填）

### 新：你现在可以……

- 校外看回放不用再找设置了：原来的「WebVPN 中转」开关退休，客户端现在全自动处理——
  校内直连、校外自动走学校官方通道，少一个需要你做决定的地方。
- 课程记忆会自己长大：同一门课反复出现的术语自动沉淀进这门课的记忆，之后生成的材料
  更贴合老师的讲法；复习页能看到每一条的来龙去脉（自动确认 · 信号 ×N），
  觉得不对点「撤销」就好，撤销后它不会再被自动使用。
- AI 总结导入后会自动做一次质量抽检：讲次卡上有三态结论（抽检通过 / 抽检完成 · N 处存疑 /
  未抽检），存疑处用人话列出。提醒仅供参考，内容本身可以直接用。

### 修：……更稳了

- 修复了学校服务闪断时被弹回首页、整个桌面点不动、退出后耳机里还有声音在放的问题——
  现在原地保留你正在看的课，服务恢复后一切照旧。
- 修复了部分云端生成的字幕没有标点的问题：标点恢复在云端重新上线，长句正常断句。
- 修复了新安装时打开「考核雷达」报错的问题，现在开箱即用。

### 安：……更安全了

- 《安全与隐私架构》说明完成一轮逐条对账：外联服务器清单校准为 10 个并附逐主机对账，
  云端任务的加密信封里带什么、谁能解封，都写得明明白白。更新到本版即可，无需任何操作。
```
