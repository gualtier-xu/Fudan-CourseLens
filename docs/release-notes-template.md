# Release Notes 模板（client-v* 发布用）

> 用法：每个版本一段，复制下方模板填写。只写学生能感知的变化；内部模块名一律不出现。

```markdown
## 版本 X.Y.Z（YYYY-MM-DD）

### 新：你现在可以……
- （每条一句白话+一句为什么；没有就删掉本节）

### 修：……更稳了
- （用户遇到过的问题用「修复了……」；没遇过的合并成一句「若干稳定性改进」）

### 安：……更安全了
- （固定三段式：影响什么 / 哪个版本起修复 / 你需要做什么——默认答案是「更新到本版即可」）
```

纪律：
- 第二人称，句子能读出声；每条 ≤2 句。
- 安全条目不写攻击细节、不写内部路径（口径见 U5 卡3：影响面/修复版本/动作三要素）。
- 更新卡（应用内横幅）只取第一条「新」或「修」，≤30 字。
