# Windows 安全提示图文指引（CourseLens 0.1.0）

> 面向第一次安装 CourseLens 的同学。这一页只讲一件事：Windows 拦你的时候，每一步该点什么、为什么。安装包只负责第一次安装；之后的升级都在应用内完成。

## 情形一：弹出「已保护你的电脑」（Windows SmartScreen）

双击 `CourseLens-0.1.0-setup.exe` 后，如果看到蓝色的「已保护你的电脑」窗口：

1. 不要点默认的「不运行」。点窗口里的**「更多信息」**。
2. 展开后会出现一行说明和**「仍要运行」**按钮，点它。
3. 之后按安装向导正常安装即可。

### 为什么会有这一步

Windows 对「没有数字签名、下载量还很少的新软件」一律先拦下来问你，这是系统默认的防陌生软件策略，和这款软件本身好坏无关。CourseLens 是学生项目，现阶段没有购买代码签名证书（那是给安装包办的「数字身份证」，需要一笔固定开支），所以你会遇到这一步。等我们攒够了第一批用户和经费，会补上正式签名。

### 不点「仍要运行」，怎么确认安装包没被动过手脚

安装包旁边有一份《校验单》（`CourseLens-0.1.0-checksum.txt`），里面记着这份安装包的 SHA-256 指纹。核对方法：

1. 把安装包和《校验单》放在同一个文件夹。
2. 在该文件夹的地址栏输入 `powershell` 回车（或按住 Shift 在空白处右键 →「在此处打开 PowerShell 窗口」）。
3. 输入：`certutil -hashfile CourseLens-0.1.0-setup.exe SHA256` 回车。
4. 把输出的一长串数字与《校验单》里的对照，**完全一致**再安装。

两串数字一致，说明你手上的文件和发布的那份逐字节相同，没有被网络传输或中间环节改过。

## 情形二：Smart App Control（SAC）拦截

如果你的 Windows 开了 **Smart App Control**（「Windows 安全中心 → 应用和浏览器控制」里查看），它可能直接拦下未签名的安装器或卸载器，弹窗文案类似「已阻止…」。

- SAC 开启的机器上，安装或卸载被拦属已知情形：安装器当前不签名，SAC 对没有签名记录的新软件默认拒绝。
- 被拦的具体文件名可以在「事件查看器 → 应用程序和服务日志 → Microsoft → Windows → CodeIntegrity」日志里看到。
- 遇到这种情况：把 CodeIntegrity 那一页截图（可先脱敏设备名），发到[官方仓 Issues](https://github.com/gualtier-xu/Fudan-CourseLens/issues) 反馈最快。目前可以先关闭 SAC 或换一台未开 SAC 的机器安装，安装完成后再到安全中心把 SAC 重新打开；我们会在签名落地后复验这条路径。

## 装好之后的安全边界（一句话版)

- **升级**：应用内自动检查新版本，装不装由你确认，默认不静默；每次更新的清单都要通过签名校验，验不过一律拒绝安装。
- **卸载**：卸载时选「保留学习数据」（推荐），重装回来一切如旧；命令行静默卸载不弹框，学习数据同样默认保留（记入卸载日志）。
- **数据**：学习资料和凭据都在你自己的电脑上（凭据经 Windows DPAPI 加密）；详见 README 的「安全与隐私架构」一节与《隐私与数据说明》。
