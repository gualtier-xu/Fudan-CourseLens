# CourseLens 设置与隐私指南

「我的 CourseLens」把学习数据、外观、连接和隐私集中在一个紧凑设置中心。外观偏好保存在这台电脑的界面本地存储里；在线、授权、统计、自动化和删除状态必须来自后端证据。

## 学习与数据

学习统计默认关闭。启用后才记录本地观看时间、学习时段、回看片段和倍速。可随时关闭统计或删除指定学期数据。删除操作需要确认，同一操作重复提交也不会重复执行。

数据为空时不显示虚假的 0 值结论，而是说明统计尚未启用、当前学期没有记录或后端无法确认。

## 外观

支持浅色、深色、跟随系统、减少动态效果、字体大小和界面密度。此类纯视觉偏好保存在这台电脑的界面本地存储里，不会伪装成服务器状态，也不会包含课程身份、登录状态或在线结论。

## 账户与连接

设置中心显示以下证据：本地后端、GitHub API、GitHub App 授权、Worker、Mailbox、端到端加密验证、本地凭据保存和统计同意。每项包含状态、来源、最近确认时间、过期时间、闭集错误码和可执行动作。

可用操作包括诊断连接、重新授权 GitHub、测试加密通道、打开高级诊断、撤销云端凭据、关闭统计、删除本地统计和查看数据边界。
首连顺序为：授权 → 安装 CourseLens App（仓库范围先选 All repositories，专属仓库尚未建立时无法精确指定）→ 创建专属仓库并完成初始化 → 把安装范围收紧为仅两个受管仓库 → 加密通道测试。客户端按当前证据把下一步做成唯一主按钮：未装 App 时是「安装 CourseLens App」，已装而仓库未建时是「创建专属仓库并完成初始化」，仓库已建而范围不精确时是「调整安装范围后继续初始化」。安装完成前 GitHub 拒绝读取两个专属仓库属正常现象，无需重新授权。
初始化、修复、加密测试与密钥轮换提交后，主按钮进入「进行中」状态并自动轮询连接状态：完成、推进到下一步或失败都会有一次明确通知；约两分钟仍无结论时会提示「仍在进行，可手动诊断」，不会再出现提交后毫无反馈的情况。
Worker 环境缺少加密密钥时，「高级操作与诊断」会出现「轮换 Worker 密钥」按钮，一次确认后自动重新生成并上传密钥；诊断区会以「缺少密钥：…」一行明示缺什么。
「复制连接诊断」与学习页的「复制脱敏诊断」是两个不同按钮：连接诊断复制连接快照的闭集状态码与环境缺钥清单，与连接卡显示同源；应用级脱敏诊断只复制各域的一行状态码。
远程动作失败时，主操作旁的内联错误区以闭集中文文案呈现，并原样透出闭集失败码（`permission_denied` 类还标注被拒的端点类别），toast 与行内区使用同一文案；未安装 App 期间的仓库读取被拒有专用指引说明「安装前读不了属正常」，不再显示一排独立故障；失败原因是 App 未安装时，处方指向「先安装 CourseLens App」而不是重新授权。

## AI 用量档位（点选即生效）

DeepSeek 用量偏好不用对数字：设置 → AI 与处理里四档卡片——
「省着用（10 万/日）」「日常够用（推荐，30 万/日）」「放开用（100 万/日）」
「不限」，点一下立即保存生效；已生成的结果不受影响。本机实际用量是透明的：
AI 用量行按月显示问答与摘要次数，任务中心可看每次任务的 token 消耗与本机累计。

低频操作按需出现：轮换 Worker 密钥只在诊断到环境缺钥时出现在「高级操作
与诊断」折叠区；「去开启云自动化」入口只在云自动化还没开启时出现在初始化
完成卡。令牌过期时修复链路只处方「重新授权」，不会把专属仓库已就绪的
你拽回全套首跑流程。

## 自动化资源熔断

「自动学习材料」运行受账号级熔断保护：默认按日限制 20 个讲次、2000 runner
分钟和 200 万 DeepSeek token（可在自动化配置中调整），任一项达到上限时
剩余工作延后到下一个窗口，而不是失控重跑；手动发起的单次任务不经过这个熔断。

## 任务中心的估计与证据

任务抽屉是一个分层的操作面板：顶部是活动数与诚实的完成摘要（只有当每个活动任务都有后端完成上界时才显示「预计全部完成还需 ≤ N 分钟」）；其下按「进行中 → 需要处理 → 历史记录」分层展示任务。

每个任务卡展示当前阶段、语义阶段轨（完成/进行中/等待/已跳过，失败与证据过期有独立形状与文字，不依赖颜色单一通道）与一句 ETA。估计按证据分层呈现：

- **排队等待**：显示「已等待 X 分钟」。只有当受信 Worker 运行历史积累了至少 5 次可比观测（时间戳完整有序、命中受信 Worker/工作流/受信提交、未取消未跳过）后，才显示「通常还需 A–B 分钟开始」；样本按「精确工作流+Runner 类别+管线 → 工作流+Runner 类别 → Worker 全局」分层回退，样本有 30 天时效与数量上限。排队等待绝不显示整体百分比。
- **处理中**：显示「预计还需 A–B 分钟」，附一行证据说明（例如「依据：本次实时速度 + 6 次同类任务 · 可信度中」）。单次事件对估计的修正超过既有有界步长时，区间降级为低可信并标注「重新估算中」；证据过期显示「等待重新确认」。
- **完成**：显示实际用时；当保存了「实际 vs 最初预计」的校准记录时，显示「比最初预计早/晚 N 分钟」。

同一讲次的字幕+摘要任务在任务中心合并为一张「学习材料」父卡（仅展示层合并，不创建、不改写任何任务记录）；产出 chips 来自后端 requested_outputs 闭集，未完成的产出完整呈现。原始 estimate_basis、错误码等标识保留在每个卡片的「技术详情」中。

## 自动学习材料（可选，默认关闭）

「自动学习材料」是显式选择开启的云端无人值守流程：把你所选的已保存复旦账号凭据，以及所选输出需要的 DeepSeek API Key，以加密形式托管到你自己的 GitHub Worker 仓库 `courselens-worker` 环境的 Environment Secrets。开启后，GitHub Actions 在每天 13:00 和 22:00（北京时间，固定不可配置）检查已选课程的新讲座，只处理你明确勾选的课程与输出（字幕、总结、章节、可选课件 OCR）。本机关闭时也能完成生成；结果加密上传，云端最长保留 30 天，本机导入验证后会更早删除云端副本；云端只保留最新一份加密续跑状态，最长 90 天。

开启流程分五步：选择范围（账号、课程、输出，课程默认全不选）→ 确认托管（明确列出目标仓库与托管内容的披露面板，勾选框默认未选）→ 加密上传（本机加密库内读取凭据，前端从不输入、不显示、不暂存秘密值）→ 云端验证（一次专用验证工作流，凭据被拒即失败）→ 已启用。任何配置、账号或 Worker 变化都会使验证失效并暂停计划任务，直到重新验证通过。

已知凭据被拒或身份不符会立即打开账号熔断，停止后续计划登录，直到你执行「更新账号」重新验证；「暂停自动处理」保留托管数据只停计划；「删除云端凭据与状态」按固定两步确认后停止任务、删除精确命名的 Secrets/Variables/Artifacts 并核实清空，未完成时进入可恢复的删除未完成状态。运行历史只显示时间、触发方式、闭集状态码、发现/生成/延后计数与导入状态，不显示课程标题、账号标识或原始日志。

配置完成后，学习页顶部会出现一张云控制面卡：按当前状态显示可用操作（立即运行、重试导入、重置保护闸、更新账号、撤销云端授权、抹除云端数据）。前四类直接执行；撤销授权与抹除云端数据属于不可逆操作，需要连续点两次确认。初始化完成总结态也会提供「去开启云自动化」入口，带你回到学习页选课开启。每个操作的真实结果都以刷新后的连接状态为准。

## 数据边界

- 本地后端只监听 loopback。
- 复旦课程缓存按已验证身份哈希隔离。
- 未验证身份前，API 不返回课程、课次和学习记录。
- 退出登录立即清空前端 DOM 和内存中的课程信息。
- DPAPI 文件只保存密文，不回显密码、令牌或 API Key。
- 前端不接收上游课程 URL、Cookie、Referer、密码或外部响应正文。
- 课程目录刷新复用已验证的 WebVPN/iCourse 会话；直连回退只采用内存中的短时 bearer 并核对身份，不重复提交 UIS 密码。
- 目录错误只输出闭集状态码、路由类别和计数；目录暂时失败不会被伪装成复旦账号登出。
- GitHub Worker 只在任务期间使用短时授权处理密封载荷。
- 客户端不读取 GitHub 账单或用量接口，GitHub App 也不请求账单读取权限。
- 自动学习材料默认关闭；开启后凭据只存在于你自己的 Worker 仓库 Environment Secrets（GitHub 加密存储、无法读回），本机数据库、日志、事件流和任务载荷不含任何秘密值。
- 云端 Artifact 在本地验签和事务导入后进入可验证清理流程。

隐私与数据的完整口径见[《隐私与数据说明》](privacy-notice.md)，与 README 的[「安全与隐私架构」](../README.md#安全与隐私架构)保持一致；删除、导出与恢复的操作细节见本指南上文各节。
