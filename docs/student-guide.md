# CourseLens 学生使用指南

写给第一次打开 CourseLens 的你。每天怎么用的主线速览见[《快速上手》](getting-started.md)；首跑、授权与故障恢复的完整说明见[《学生新手教程》](student-onboarding.md)。跟着界面走一遍如有对不上的地方，欢迎到 [GitHub Issues](https://github.com/gualtier-xu/Fudan-CourseLens/issues) 提一条：每一条报障都有人回，说的是人话；贴截图前先脱敏（不要出现学号、密码和真实课程名）。

## 第一次打开会发生什么

1. 客户端启动后自动打开 CourseLens 窗口，本地服务只跑在你自己的电脑上。
   界面会先显示上次保存的课表快照（标注快照时间），会话在后台恢复，
   不用对着「正在恢复」干等。
2. 跟着引导走五步：先了解工作方式 → 连接复旦课程平台 → 确认课程目录 →
   准备生成能力 → 开始学习。每一步都能随时回来重做。
3. 都绿了之后，进入「学习」页选一门课，开始用。

## 五个常用入口

- **学习页**：选课程、进讲次；字幕、总结、资料、复习四块内容都在讲次里。
  新课第一次出现时会轻问一句「要不要为这门课开启云端自动处理」，开与不开
  都行，以后随时能在课程行或设置里改。学期显示成人话（「2026-2027 ·
  第 1 学期」），筛选下拉里也是。
- **文稿检索**：在字幕里找一句话——输入关键词，显示「第几处、共几处」，
  Enter 往下跳，Shift+Enter 往回跳。
- **考核雷达**：老师课上提到的考试、作业截止会自动记进「这门课最近要交
  要考」，确认后才常驻显示；觉得不对可以忽略。
- **课表**：按学期展示每周安排，冲突和考试周会特别标注；课表数据的来源
  与导出规则见[《学生课表说明》](student-timetable.md)。
- **数据管理**：看每门课占了多少空间；能删导出的资料，也能一键解锁卡住
  的记录。每个按钮删什么、能不能恢复都有说明，详见[数据管理页说明](course-data-management.md)。

## 关于 AI 用量

- 字幕校对和摘要用你自己的 DeepSeek Key；合并摘要时会顺带提取考核事件
  和核心结论。用多用少在设置里选档：「省着用 / 日常够用（推荐）/ 放开用 /
  不限」，点一下就生效；实际消耗在 AI 用量行和任务中心透明可查——
  每次任务的 token 消耗、本月的合计都有记录。
- 「解释」按你插旗的那一刻定位那一段，AI 结合前后文讲清楚；没有配置
  DeepSeek Key 时会直接说明原因，已生成的随时能看。

## 数据与隐私速览

- 学习数据保存在这台电脑上；只有你发起的生成任务会把必要的课程材料加密
  送到你自己的云端仓库处理，结果加密回传，云端只作加密暂存（最长 30 天）。
  没有遥测：固定清单之外的统计、埋点、上报一律不存在。
- 学号、密码和 API Key 只输入客户端本地的受保护表单，经 Windows 加密
  （DPAPI）后存盘；日志、界面和诊断输出都不会回显它们。
- 卸载或重置前，数据管理页可以先把资料导出带走；卸载时选「保留学习数据」
  （推荐默认），笔记、字幕、进度原地不动，重装回来一切如旧。
- 不卸载、只想清空重来：设置的危险区有「客户端重置」，输入「重置」确认
  后执行，完成后客户端自动关闭；有任务在跑时重置会被拒绝，而不是半途
  执行。重置不可恢复，清什么、留什么见[《客户端重置（设置危险区）》](client-reset.md)。

## 遇到问题

- 顶部状态条变红先重启客户端（本地服务断开时的标准动作）。CourseLens
  一次只跑一个：再次打开不会开出第二个实例，而是把还活着的那个课程窗口
  带到屏幕前面。想彻底重启（比如刚升级完），关掉窗口再从开始菜单打开
  即可——升级都在应用内完成，不要重跑安装包。
- GitHub 连接问题按「设置 → 账户与连接」的证据提示逐项处理；更完整的
  恢复顺序见[《学生新手教程》](student-onboarding.md)。
- 校外看回放打不开：多数情况不用任何设置，客户端会自动走学校官方的
  校外通道；仍打不开时，按 README[「校外使用：回放怎么才能打开」](../README.md#校外使用回放怎么才能打开)一节的最小清单处理。
- 还不行就去 [GitHub Issues](https://github.com/gualtier-xu/Fudan-CourseLens/issues)
  提一条。「设置 → 更新与帮助」里的诊断信息本身已严格脱敏，可直接截图。
