# CourseLens 学生新手教程

本教程对应客户端中的「帮助与新手引导」。静态说明随客户端提供；步骤完成度、连接结论和操作结果只读取后端证据。

## 安全规则

- 学号、UIS 密码和 DeepSeek API Key 只输入 CourseLens 的受保护密码框。
- 不把秘密粘贴到聊天、教程搜索、Issue、日志、控制台或命令行。
- 涉及秘密输入时不截图、不录像、不启用 trace，也不采集控制台内容。

## 推荐顺序

1. 打开 CourseLens（安装版从开始菜单启动），确认本地后端可用。CourseLens 一次只运行一个实例：再次打开会把已运行的窗口带到前台而不是另开一个；想干净重启（比如刚升级完），关掉窗口再从开始菜单打开即可。
2. 在客户端内完成 GitHub 授权（设备验证）。
3. 按客户端引导打开官方 CourseLens App 安装页：仓库范围先选 **All repositories**（此时你的两个专属仓库尚未建立，GitHub 无法精确指定）。
4. 回到客户端点击「创建专属仓库并完成初始化」：客户端自动创建（或复用）你的专属公共 Worker 与私有 Mailbox，无需手动创建或搜索仓库。
5. 按客户端引导在 GitHub 安装设置中把 App 范围收紧为仅两个受管仓库。
6. 执行加密通道测试，确认端到端加密链路可用。
7. 在本地安全表单完成复旦身份认证。
8. 等待客户端自动发现当前身份实际可访问的课程。
9. 选择课程并开始在线播放、字幕或学习资料任务。

该首次运行流程与操作系统安装包解耦：Windows 与未来的 macOS 安装包都只在本地安装后启动同一个流程；安装包自身不登录 GitHub、不创建远程仓库、也不修改 App 权限。

GitHub 的几个状态必须分开理解：Device Flow 授权已完成、App 已安装（首装范围为 All repositories）、两个专属仓库已创建、安装范围已收紧为仅两个受管仓库、Worker 已验证、加密通道已测试。任一项缺失时，客户端都会按当前证据把下一步做成唯一主按钮，并给出闭集错误码与受信恢复链接：尚未安装 App 时主按钮是「安装 CourseLens App」；已安装而仓库未建时是「创建专属仓库并完成初始化」；仓库已建而范围不精确时是「调整安装范围后继续初始化」。安装完成前 GitHub 拒绝读取两个专属仓库属正常现象，无需撤销重授。Worker 环境缺少加密密钥时，连接卡「高级操作与诊断」会出现「轮换 Worker 密钥」按钮，一次确认后自动重新生成并上传密钥。

## 应用内新手引导

客户端内置一个五步引导页（普通页面，不遮挡其他功能）：先了解工作方式、连接复旦课程平台、确认课程目录、准备生成能力、开始学习。引导只汇总既有后端证据，不从页面文案反推状态，也不会替用户登录、刷新目录或发起远程任务。

引导记录只保存教程进度（版本、新/已跳过/已完成、是否已自动展示过），与服务 readiness 完全分离：

- 首次安装自动打开一次；跳过后当前版本不再自动弹出，已完成或已跳过都不改变任何连接或同意设置；
- 老用户（已有保存账号、已确认课程目录或历史任务）升级后不会被自动打断，引导按「已跳过」处理；
- 已登录账户菜单和「设置 → 更新与帮助」都提供「新手引导」入口（学习空态的入口已移除，保留在账户菜单与设置）；手动重新打开不会把状态改回「新」，只有再次点击「完成引导」才写完成；
- 跳过或完成写入失败时，引导留在当前页并给出重试入口，不在前端伪造成功状态；
- 引导状态保存在本地应用状态中，不使用 localStorage；恢复出厂清空应用状态后，下一次启动会重新显示引导。

## 课程目录

未登录、会话过期或身份未经确认时，客户端不会返回或显示本地缓存中的课程名称、教师、课程 ID、课次和学习记录。登录成功后，客户端逐门确认权限并自动发现课程。可使用学期、院系、教师、学习状态和关键词筛选，目录采用有界分页。

课程行的顺序可以自己调：直接拖动行，或选中行后按 Alt+↑/↓ 都可以。顺序只保存在这台电脑的界面本地存储里，属于你的视图偏好，不影响课程目录本身，换设备不会跟着走。

缓存按已验证身份的哈希命名空间隔离。缓存过期时显示「上次缓存，正在重新确认」或「数据已过期」，不会继续显示绿色成功状态。退出当前会话会立即清空页面和内存中的课程信息，但不会删除本机 DPAPI 保存的账号。

复旦平台登录与课程目录刷新是两个独立状态。若页面显示「登录已成功，但课程目录暂时不可用」，优先重试目录或运行网络诊断；只有客户端明确显示会话过期、身份不一致或需要额外身份验证时才重新登录。不要为 CourseLens 关闭学校账号的两步验证。客户端复用同一个已验证会话，不会为目录刷新再次提交密码。

## 播放与学习资料

- 在线播放支持倍速、画中画和全屏，自动生成字幕。字幕的字号、背景深浅和贴底位置可以长按字幕按钮调整；全部快捷键在播放器里按 ? 查看。
- 没听懂？按 X 或标记按钮，在时间轴上落一个点。把鼠标放到点上可以「解释」（AI 用你的课程资料解释这段，走你的每日解释额度）或「懂了」（点从时间轴收起，书签数据还在本机）。
- 讲次资料（课件 PDF）在你的电脑上直接生成：垃圾页（纯色页、翻页残影、窗口残影）在本地就被识别并跳过，只有真正有内容的页会进入后续处理；云端不再参与这一步。
- 字幕任务遇到媒体会话过期（比如隔了一夜续跑同一讲）会自动重新获取会话材料并重试当前段落，不再一失败就整单重来；重试次数有上限，仍失败时会告诉你最后一次的具体原因。
- 「学习洞察」默认关闭。开启后进度条会标出你反复回看的位置，数据只保存在这台电脑上，可随时关闭或一键抹除。
- 字幕、OCR、摘要、章节、AI 搜索、疑问解释、测验、课件对齐和跨课程分析统一进入任务中心。
- 字幕任务生成完成后会出现一次轻提示（不会打断你正在做的事）；回到对应讲次播放即可开启字幕。
- 没有可靠处理量时显示「不确定进度」；没有可靠 ETA 时显示「暂无法估算」。
- 取消只表示请求已发送，收到后端或 GitHub 终态后才显示「已取消」。
- 「暂停」就是让云端机器马上停下来：在飞的云任务会立即取消，已完成的部分都保留；点「恢复」会从检查点接着做，不用从头再来。
- 讲次已有字幕时，「AI 处理」按钮负责 AI 总结；字幕和 AI 处理已完成或已由云自动化排上时，按钮会自动收起，状态看任务行。

## 搜索、复习和知识关系

普通搜索使用本地索引。AI 回答必须引用课程证据。疑问标记从播放时间点生成，测验和复习计划必须有可追溯来源。跨课程知识关系只有在两门课程分别存在真实证据时才建立，并支持关系列表、概念图、跳转时间戳、忽略和重新分析。

## 本地与云端每日调度

本地调度默认关闭，凭据只保存在本机 DPAPI 中。云端调度也默认关闭，启用前必须确认：

- 个人 Worker 完整性和 Mailbox 加密通道已验证；
- 当前配置哈希对应的验证 workflow 成功；
- 每日讲次、runner 分钟和 DeepSeek token 预算已设置；
- 了解一键撤销会停止调度、处理活动任务并删除托管 Secrets 和 Variables。

Secret 名称存在不代表凭据有效，按钮点击或请求已接受也不代表成功。

## DeepSeek

- DeepSeek API Key：从 [DeepSeek API Keys](https://platform.deepseek.com/api_keys) 创建，通过本地受保护密码框保存或撤销。

CourseLens 不接收邮箱账号或授权码，也不发送邮件推送。运行状态、失败、预算和待导入结果统一在客户端任务中心与自动化工作区查看。

## 错误恢复

客户端错误码可跳转到恢复教程。常见恢复顺序为：检查本地后端、诊断网络、重新登录复旦、重新授权 GitHub、验证 Worker、测试加密通道、检查预算熔断、重试导入或确认云端清理。不要通过删除数据库、DPAPI 文件或 force push 绕过状态检查。
