# 学术编辑风静态原型：信息架构指导

## 状态、优先级与边界

状态：**本轮静态原型的唯一 IA 决策源**。优先级高于旧的视觉/导航意图；若与既有安全、隐私、认证、API、任务生命周期或可访问性合同冲突，后者优先。本文件只定义旧文档所涉 UI/IA 意图，不改写产品合同，也不授权产品迁移。

本轮只可编辑 `runtime/cache/ui-academic-editorial-prototype-20260905/index.html` 和要求的截图。原型数据必须明显为合成数据；不得出现真实课程、凭据、URL、账号或运行时资料。禁止修改 `frontend/`、`tests/`、`src/`、`worker/`、`runtime/`（前述原型缓存文件除外）、`docs/handoff.md`、`docs/ui-design-system.md`。

## 问题诊断与目标 IA

旧四项“学习 / 搜索 / 课表 / 设置”并列导航把动作和上下文误做成目的地：搜索是跨内容的全局动作，课表是选课上下文；两者不应抢占主场景。目标只有一个持久主场景：**学习**。

```text
学习（课程/讲次选择 → 学习桌）
├─ 课程/讲次标题下：今日与本周安排（渐进披露的课表上下文）
├─ 全局搜索 overlay：快速跳转 → 完整检索 / 证据回答
├─ 任务：右侧抽屉
└─ 账户菜单 → 设置（独立的页面级内容）
```

学习桌的播放器、字幕、笔记、资料、复习结构是已批准范围，保持原有结构和视觉，不借本轮重做。

## Shell

### 桌面

顶栏左侧是可返回学习的字标；右侧依次是带 `Ctrl K` 提示的搜索、任务、账户。不要为了只剩一个目的地而保留孤立的“学习”标签。课程与讲次位置放在内容区，只在“课程 → 讲次”这种真实层级中显示面包屑。账户菜单进入设置；主题仅在设置中。设置页必须有明确的“返回学习”入口。本轮不引入 URL 路由或路由框架。移除“学习 / 搜索 / 课表 / 设置”一级导航。

### 移动

移除四项底部导航。顶栏保留返回或字标、搜索、任务、账户；页面层级应由真实历史栈或等价可预测状态维护，浏览器返回不得随机跳到无关场景。学习桌与选择态的返回都回到其上一级学习上下文。

## 搜索：一个 overlay，三个层级

采用 PowerToys Run 的**交互逻辑**，不用其视觉皮肤：学术编辑风、居中 command palette、打开即聚焦输入并提供 autocomplete。禁止创建搜索页面或路由。

1. **紧凑态**：合并本地目录与已有全文 API 结果，首屏最多 8 项，按“字幕时间点、课程讲次、笔记/书签/资料、操作”分组。每项给出足够上下文和明确目的地，不能是死路。桌面宽度建议 640–720px，高度不超过约 70vh。
2. **完整检索模式**：仍在同一 overlay，保留现有 `limit=50`、索引状态、空态、失败态和全文结果；桌面在原位置扩展为不超过约 1040px、84vh 的稳定阅读面，移动近全屏。
3. **证据回答模式**：仍在同一 overlay，承载现有 POST search/answer 的回答、证据和失败/不可用状态；不得把模型回答伪装成检索事实。

键盘：上下键移动活动项，`Enter` 打开当前项或执行明确操作，`Esc` 只退一级（完整/回答→紧凑→关闭）。鼠标、触屏与键盘都可到达全部结果。认证未就绪时先显示 auth-ready 门禁及可执行入口；不能伪造搜索、索引或回答已经可用。

无障碍：容器为 `dialog` + `aria-modal="true"`；输入为 `combobox`，设置 `aria-autocomplete="list"`，结果为带命名分组的 `listbox`/`option`，用 `aria-activedescendant` 表示活动项。每个 `option` 自身只执行一个动作，不在其中嵌套按钮。复用 `openOverlay` 的背景 `inert`、焦点圈闭、`Esc`、关闭后归还触发元素语义；状态变化通过 `aria-live` 宣布。粗指针目标至少 44px。

## 课表：学习选择态的上下文

在课程/讲次选择态标题下加入渐进披露的“今日与本周安排”。优先使用原生 `details`/`summary`；默认折叠摘要，例如“今天 2 节 · 下一节 15:25 计算机网络”。展开后按时间顺序列出，不制作七列教务表格。桌面可并列“今天 / 本周稍后”，窄屏改为单列。仅在数据支持时，点击课程才进入或选中对应课程。课表不常驻学习桌，避免挤占播放器和阅读区。

能力必须有诚实承载位：展开区提供高频周切换、课程会议、冲突与刷新；低频学期起始日和 ICS 放入“课表设置”二级披露或设置页的课表分组。展示未认证清空、缓存 stale、需要起始日、空、加载、失败、冲突等静态状态；冲突除颜色外必须有文字和/或图标说明。

## 与任务、设置的关系

任务继续是右抽屉，不成为页面；活动数和失败提示必须有文字或可访问名称，不能只靠圆点颜色。设置保留独立的页面级内容，但只从账户菜单进入；课表设置可在那里承接低频配置。本轮不要求给设置新增 URL 深链接。不得移除或弱化既有会话、隐私、代理、更新、危险操作确认及诊断脱敏含义。

## 视觉与响应式硬约束

- 全局字体仅 `"Times New Roman", "SimSun", "宋体", serif`；无在线字体、无新依赖、无 emoji 图标。
- 亮色：canvas `#F7F3EB`；surface `#FFFCF7`/`#FFFFFF`；ink `#172033`；navy `#1E3A5F`/`#071D33`/`#E9EFF5`；gold `#B7791F`/`#B45309`；muted `#667080`；line `#DED6C9`；line-strong `#8A8272`；danger `#B4232D`。
- 暗色：canvas `#111927`；surface `#182230`/`#1D2A3C`；text `#EFE9DC`；title `#A9C4E0`；button `#2E5285`；gold `#D19E3F`/`#DCA742`；stage `#0C1626`。
- 禁绿色、禁渐变。正文 `16.5px/1.75`，控件 16px，辅助文字最小 13.5px，数值使用 tabular numerals，粗指针触达至少 44px。
- 宽度 ≥1000px 的学习桌仍左右同屏；375px 必须零水平溢出。375px 播放器必须看见播放、当前/总时长、CC、全屏；次要控制可隐藏，但不可只剩进度条或裁掉控制栏。

## 状态、行为流程与验收

所有静态状态都应明确说明这是合成演示。原型交互只用内联演示脚本，不发起 `fetch`，不写 `localStorage`，不连接产品 API。搜索：触发器→紧凑态→完整检索或证据回答→`Esc` 逐级回退→关闭并归还焦点。课表：折叠摘要→展开安排→周切换/课表设置→课程选择（有数据时）。任务：打开右抽屉→关闭并归还焦点。

交付截图写入原型目录下新的 `ia-revision/` 子目录，不覆盖既有截图。最小集：1440 课程页课表折叠、1440 课程页课表展开、1440 学习桌搜索紧凑态、1440 完整检索或证据回答、375 课程页展开、375 搜索、375 学习桌播放器；另至少一张暗色搜索或课表。无需重拍无关旧屏。

验收：字体检查；禁止字体/绿色/渐变扫描；控制台 0 错误；键盘路径、焦点归还与状态演示；截图元素 bounding boxes；375 零溢出、1000 学习桌同屏。原型目录本就被 Git 忽略，因此 `git status` 应与 preflight 相同；另用 `git check-ignore` 证明原型与新截图仍在忽略范围。报告范围和未验证的产品合同。

## 产品迁移时必须保留的现有合同与下一门禁

未来迁移必须保留：认证 ready 门禁；已有全文 API、`limit=50`、索引/空/失败状态、POST search/answer；任务右抽屉的后端状态与动作；浮层焦点管理；设置的会话、DPAPI/凭据、隐私披露、代理、更新及危险操作确认；真实课表的学期/周/会议/冲突/刷新/ICS/起始日能力；播放器恢复、字幕时间点、书签与复习数据语义；所有安全、隐私、API 和生命周期合同。

下一门禁：只有静态原型的审美和交互获批后，才可另行编写正式产品迁移提示词。本文件和本轮提示词均不授权迁移或产品代码修改。
