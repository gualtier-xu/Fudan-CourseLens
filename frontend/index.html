          重置

          重置应用

          重置会清除课程目录、任务、课表、搜索索引、观看进度、书签、测验、复习计划与本机保存的凭据，也会清掉浏览器端小数据（主题、界面字号、课程排序、学期筛选），然后关闭应用；重新打开后需要重新登录。重置不是备份，删除的内容无法恢复。卡住的任务会先被解锁收尾，再执行重置。

          字幕、AI 产物与课件等课程派生产物默认保留；重置前会自动在本地生成一份脱敏数据摘要回执。

          搬家与备份

          一键把学习数据打成加密搬家包：观看进度、AI 总结与问答、复习卡和间隔重复记录、上传的资料、课件与字幕都在里面。换电脑时在新机导入即可原样安家；平时放 U 盘或网盘就是一份自己的备份。CourseLens 不上传它，也只有设密码的人能打开。

          保存的密码和密钥出于安全设计不进包：新机需要重新登录复旦账号、重新连接 GitHub 授权、重新填写 DeepSeek Key（导入完成后会给这份清单）。

          先了解工作方式

          CourseLens 运行在你自己的电脑上。在线播放和课程目录依赖复旦课程平台的登录会话；字幕、笔记等生成任务会按你的设置使用加密云端处理，两种连接相互独立、状态分开显示。

          在你明确点击登录、刷新或生成之前，CourseLens 不会自动访问学校平台或发起远程任务。学号、密码和 DeepSeek API Key 只需要在应用内已有的受保护输入框中填写，引导本身不会收集任何秘密。

          字幕、笔记等生成任务使用加密云端处理：完成 GitHub 连接后即可用，不需要额外开启开关；数据处理范围、保留期与撤销路径都写在《隐私与数据说明》里（设置页「隐私」节可查看）。
